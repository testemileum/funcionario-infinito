# Atribuição de origem

O **Funcionário Infinito** é uma obra derivada do **BMad Method**, projeto open source
criado por Brian Madison e mantido pela comunidade do BMad Method.

- Projeto original: <https://github.com/bmad-code-org/BMAD-METHOD>
- Licença: MIT
- Versão de origem deste fork: `6.13.0-next`, commit `f033e70a` (18/09/2026)

O Funcionário Infinito **não é afiliado, endossado, patrocinado nem certificado** pelo
BMad Method, pela BMad Code, LLC ou por Brian Madison.

## O que veio do projeto original

A arquitetura de skills, os fluxos de trabalho de planejamento e desenvolvimento, os
agentes e a maior parte da documentação técnica têm origem no BMad Method. O histórico
de commits deste repositório foi preservado na íntegra justamente para que essa origem
seja verificável por qualquer pessoa.

Os contribuidores do projeto original estão creditados em [CONTRIBUTORS.md](CONTRIBUTORS.md),
mantido sem alterações. O [CHANGELOG.md](CHANGELOG.md) também foi preservado como registro
histórico do projeto de origem.

## O que é próprio do Funcionário Infinito

- Identidade, nome e marca
- Materiais de curso e formação
- Skills e módulos desenvolvidos especificamente para este projeto
- Suporte e comunidade
